# Maram AI — Experimental Voice Assistant
            Created by : Ayoub Saadaoui
Maram AI is an experimental AI assistant developed as a beta project to explore natural language interaction, voice-based communication, and immersive 3D experiences.

The project integrates the Ollama API to provide AI-powered conversational capabilities, alongside a 3D avatar and voice interaction features designed to create a more interactive assistant experience.

### Key Features

- **Ollama API Integration:** AI-powered conversational capabilities.
- **3D Avatar:** An interactive 3D visual identity for the assistant.
- **Tunisian Arabic Support:** Designed to understand and interact using Tunisian Arabic.
- **Voice Interaction:** Microphone-based input allowing users to communicate with the assistant through speech.
- **Conversational Experience:** A voice-oriented interaction system.
- **Password Protection:** Access protected through a password system.

### Project Status

**Beta / Experimental Prototype**

Maram AI is currently a testing project and is not intended to be considered a fully developed or production-ready AI assistant.

The main goal is to experiment with AI integration, voice communication, Tunisian Arabic interaction, and 3D avatar technologies while exploring the possibilities of a more natural human-computer interaction experience.

### Development Goals

- Explore AI-powered conversations using Ollama.
- Experiment with Tunisian Arabic voice interaction.
- Integrate 3D avatar experiences.
- Test microphone-based communication.
- Improve stability, responsiveness, and conversational quality.

**Note:** This is an experimental beta version. Features, performance, and conversational capabilities may be limited or subject to change.
